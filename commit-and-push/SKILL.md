# Commit and Push

1. Read and follow the sibling [commit skill](../commit/SKILL.md).
2. Inspect the branch, remotes, and clean worktree after committing.
3. Push the current branch to its configured upstream. If none exists, set `origin` as upstream only when that remote exists.
4. Never force-push.
5. Report the commit hashes/messages, pushed branch, and whether the worktree is clean.
