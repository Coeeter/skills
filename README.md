# Skills

A collection of personal agent workflows.

## Skills

| Skill                                                   | Description                                                    |
| ------------------------------------------------------- | -------------------------------------------------------------- |
| [commit](commit/SKILL.md)                               | Commit current changes locally                                 |
| [create-plan](create-plan/SKILL.md)                     | Make a substantial feature portable before implementation      |
| [execute-approved-plan](execute-approved-plan/SKILL.md) | Implement a feature from its approved portable plan            |
| [init-agent](init-agent/SKILL.md)                       | Set up agent context for an existing repository                |
| [second-opinion](second-opinion/SKILL.md)               | Get an independent read-only opinion from another coding model |
| [ardia](ardia/SKILL.md)                                 | Drive the Ardia browser from the terminal or browser extensions |
| [chatgpt-computer-use](chatgpt-computer-use/SKILL.md)    | Connect Codex/T3 to the installed ChatGPT Chrome and desktop runtime |

## Installation

Install with the [Vercel Skills CLI](https://skills.sh):

```bash
npx skills add Coeeter/skills
```
